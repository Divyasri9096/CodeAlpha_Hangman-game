# CodeAlpha Hangman Game

A simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

- Uses 5 predefined words
- Allows the player to guess one letter at a time
- Provides 6 incorrect guesses
- Displays the progress of the word
- Handles repeated guesses
- Handles invalid input
- Displays win and game-over messages

## Technologies Used

- Python
- Random module
- Lists
- Strings
- Loops
- Conditional statements
- User input

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in Command Prompt.
4. Run:

```bash
python hangman.py
